## 👋 About Me

I'm **Le Duc Chinh**, a Computer Science student at **Hanoi University of Science and Technology (HUST)** focused on **Java backend development**. I enjoy designing well-structured APIs, modelling data properly, and shipping software that is easy to maintain.

- 🔭 **Currently:** building backend services with **Spring Boot**, **PostgreSQL** and **Docker**
- 🌱 **Learning:** Microservices architecture, **Kafka**, **Kubernetes**, and LLM integration (tool calling, MCP)
- 🤝 **Open to:** backend internships, team projects and open-source collaboration
- 💬 **Ask me about:** Java, Spring ecosystem, REST API design, SQL
